
# Oakmont Private Banking

A responsive website template featuring a private-banking-inspired design with emerald green and gold styling.

## Pages

- `index.html` — Home page
- `login.html` — Sign-in interface
- `register.html` — Registration interface
- `dashboard.html` — Account dashboard
- `style.css` — Shared styles
- `README.md` — Project documentation

## Features

- Responsive layout for mobile and desktop
- Emerald green and gold visual theme
- Home page with service sections
- Sign-in and registration forms
- Password visibility toggle
- Dashboard balance visibility toggle
- Navigation between pages
- Accessible form labels and status messages

## Getting Started

1. Create a GitHub repository.
2. Add all six files to the repository root.
3. Make sure the filenames match the links used in the HTML.
4. Open `index.html` to preview the home page.
5. To publish with GitHub Pages, open your repository settings.
6. Select **Pages**.
7. Under the build and deployment section, choose **Deploy from a branch**.
8. Select your main branch and the root folder, then save.
9. Wait for deployment to complete and open the published URL.

## Important

This project is a front-end template. The forms do not authenticate users, registration does not create real accounts, and the dashboard is not connected to a bank.

The displayed account balance is a presentation value, not a verified financial record. Transaction history, account authentication, deposits, transfers, and payments require a secure backend and authorized financial integrations.

Do not collect or store real passwords, banking credentials, or sensitive customer information using these static pages.
